Dundas Valley Pools - SEO Enhanced Child Theme

INSTALLATION INSTRUCTIONS:

1. ZIP THIS FOLDER
   - Select all files in this folder
   - Create a zip archive named: dundas-pools-seo-child.zip

2. UPLOAD TO WORDPRESS
   - Log into WordPress admin
   - Go to Appearance → Themes → Add New
   - Click "Upload Theme"
   - Select the zip file
   - Click "Install Now"

3. ACTIVATE THE THEME
   - After installation, click "Activate"
   - The child theme is now live with all SEO improvements

WHAT'S INCLUDED:

✓ LocalBusiness Schema markup for Google
✓ Optimized meta descriptions for all pages
✓ Open Graph tags for social sharing
✓ Twitter Card support
✓ Breadcrumb schema
✓ FAQ schema (for FAQ pages)
✓ Service schema (for service pages)
✓ Canonical URLs
✓ Optimized title tags
✓ Performance improvements

REQUIREMENTS:
- WordPress 5.0+
- Astra parent theme installed
